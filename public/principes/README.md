## Convention

Chaque fiche distingue trois couches, jamais mélangées :

- **source attestée** — texte reçu ou retrouvé tel quel, avec empreinte ;
- **dérivation consolidée** — rapprochements entre sources attestées ;
- **reconstruction analytique** — ce qui est inféré, signalé comme tel.

Les fichiers sous `sources/` ne sont jamais modifiés après dépôt.
