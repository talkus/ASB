# DoctorLive

Paquet en bibliothèque standard. Aucune dépendance PyPI.

`python main.py` lance les contrôles. CERT_PLEIN n'est émis que si toutes les lignes sont vraies. Le registre des sièges est vide, le journal local ne vérifie pas une chaîne, le reçu S-24 n'est pas lu. Ces lignes échouent. C'est le résultat attendu.

La couverture 69 est la définition 23 × 3, pas une observation d'un anneau.
